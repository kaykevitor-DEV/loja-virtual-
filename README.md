# Loja Virtual

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma loja virtual, com o objetivo de praticar conhecimentos de desenvolvimento web e criação de interfaces.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## Funcionalidades

* Exibição de produtos
* Interface visual para a loja
* Organização dos arquivos do projeto

## Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
